# Cycle / epicycle encoding

Standalone geometric codec for deterministic byte streams generated from circles (cycles), epicycles, and optional torus projection. This path is **orthogonal** to fractal_zip inner tuple/gradient search.

## What this is not

Do **not** express cycle structure as fractal_zip markers (`<g…>` gradients, substring/tuple tags). That duplicates existing fz inner functionality and would compete with the inner tournament. Cycle recognition lives in the **FZCY wire codec** and optional **`cycle_inner`** preprocess arm (same integration pattern as `spiral_inner` / FZSPL).

## Geometric model (v2)

| Layer | Role |
|-------|------|
| **Walker** | Independent circle: `(min_ord, max_ord, step, phase)` |
| **Combine** | `single`, `round_robin`, `complex`, or `deferent_rr` |
| **Deferent** | Copernican reference circle subtracted before emit |
| **Byte map** | `direct` (`chr`) or `torus` (golden-angle via spiral `TorusEmbed`) |

**Round-robin** emits one walker per tick (`t mod N`), breaking sum-mod lag artifacts (e.g. old case 184 had 100% lag-38 correlation).

**Complex epicycle** sums `z(t) = Σ aⱼ exp(i kⱼ t + φⱼ)` and maps `(Re z, Im z)` through the torus byte map — quasi-periodic, high-entropy appearance from a compact recipe.

**Deferent** shifts the observer to a moving reference frame: emit `combine(walkers) − deferent(t)` before byte mapping.

## Research connections

- **Epicycles / deferent** — historical model of circles-on-circles; modern link to **Fourier series** and **almost-periodic** functions (Bohr/Weyl theory).
- **Incommensurate frequencies** — trajectories dense on a torus without short global repeat (deterministic but “random-looking”).
- **Golden-angle / phyllotaxis** — torus maps with irrational rotation; order without block periodicity (quasi-crystal analogue).
- **Wiener / Brownian motion** — stochastic limit of many oscillators; contrast with **few deterministic epicycles** storing the same visual complexity.

## Wire format (FZCY)

| Mode | Meaning |
|------|---------|
| `FZCY\x01` + v1 binary | Legacy single / sum-mod (decode compat) |
| `FZCY\x03` + v2 binary | Epicycle recipe (combine, byte_map, walkers, optional deferent) |
| `FZCY\x02` stream | Segmented literals + embedded v1/v2 recipes |

Human `<e"…">` strings in `cycle_encoding_recipes.php` are **fixture metadata only** — not on-disk fz tags.

## Experimentation

[`benchmarks/bench_cycle_epicycle_experiment.php`](../benchmarks/bench_cycle_epicycle_experiment.php) reports lag correlation, entropy, oracle size, and detect/encode latency per corpus case. With `--quick` omitted, it also sweeps a grid of 2-walker round-robin parameters @10 KiB and ranks by entropy vs lag-38 penalty.

Detection uses probe-hash catalog index, generic v2 round-robin inference (no catalog required for RR corpora), and block-wise verify for large payloads.

Fixture corpora (180–193) also ship [`cycle_encoding_fingerprints.php`](../cycle_encoding_fingerprints.php) (auto-regenerated by the build script). Catalog detect matches full-payload xxh128 in O(n) hash time — no regeneration — so 1 MiB cases encode in milliseconds.

Smoke gates (`benchmarks/smoke_cycle_encoding_recipes_180_193.php`): round-trip, lag-38/76 below 15% on 184/187/182, lag-76 below 20% on 181, minimal period ≥ 90% length on multi-walker tiers, entropy floor on small cases.

## Spiral integration

Torus byte mapping optionally uses [`/srv/http/spiral/src/TorusEmbed.php`](/srv/http/spiral/src/TorusEmbed.php). Falls back to a deterministic trig mix if spiral is unavailable. Conceptually aligned with spiral inner work; **not** a duplicate of fz tuple search.
